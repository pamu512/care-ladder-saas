Four beats, one thread

The conversation is the runtime (rolling out; the live demo uses one-tap ack links meanwhile). Every beat is timestamped into the same audit trail a facility reviewer would read.

Inform · 0:00 Mom is asked first The speaker check-in gets a plan-defined window. Most incidents end here - the family never hears about them. "I'm fine, thanks - just resting."
Acknowledge · in chat One tap, three choices Take it yourself, start a speakerphone call, or pass to the next contact. (In-chat buttons are part of the rolling-out runtime; today's demo uses one-tap acknowledgment links that work the same way.) "Noted, James. Sarah will not be contacted."
Update · free text Your reply becomes the record "Balcony again, phone inside" is stored as the case note. No forms, no console visit.
Escalate · only if quiet Countdown pressure, then calls No acknowledgment in the window means the next contact gets called - and the thread says so at every step. "Calling you now. Sarah is next if you can't take it."
