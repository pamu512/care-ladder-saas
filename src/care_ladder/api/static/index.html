Demo scenarios (family mode) · for walkthroughs only
Care Ladder is a wellness companion, not a medical device: it does not diagnose and never calls emergency services on its own - a human always decides. Camera frames are blurred before anything is saved; raw video never leaves the device. Reserved fictional numbers are used throughout demos.
Tenant isolationEvery request is session-scoped to one tenant; incidents, cases, and audit trails never cross tenants.
Fail-closed webhookUnsigned or invalid Stripe events are rejected before any plan change; billing truth only moves on verified signatures.
Privacy by defaultCamera frames are blurred or silhouetted before persist; raw pixels never leave the device pipeline.
